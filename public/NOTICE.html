Notices и границы публикации

Этот Pages-артефакт — самостоятельный HTML/CSS/JS product tour без библиотек, runtime bundles, реальных credentials и provider delivery. Он не является опубликованной Community Edition сборкой OpsWeave.

Полный исходный runtime сохраняет LICENSE-MIT, LICENSE-ENTERPRISE, EE-PACKAGES-LICENSE и reviewed third-party notices. Публичная публикация runtime остаётся fail-closed до получения отсутствующих ISC/MIT notices, разрешения Maily и ясного разрешения standalone WebSocket package.

The public demo contains only original static tour code. The private CE preparation repository preserves the upstream license files and reviewed notice inventory. No runtime image or package is distributed from this page.
